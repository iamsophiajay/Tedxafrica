# TEDx Africa Website

A modern, responsive website built for TEDx Africa to showcase its mission, programs, events, ambassadors, and community initiatives across Africa.

> **Role:** Frontend Developer

---

## Overview

This project involved redesigning and implementing a user-friendly website that reflects TEDx Africa's vision while improving navigation, responsiveness, and accessibility. The website serves as a central platform for visitors to learn about the organization, explore initiatives, read articles, and connect with the community.

## Features

- Responsive design for desktop, tablet, and mobile devices
- Modern landing page
- Dynamic navigation components
- Team and Global Ambassadors pages
- Blog section
- Legacy Talks section
- Contact page
- Optimized user experience and site navigation

## Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)
- Git
- GitHub

## Challenges

One of the key challenges was restructuring the website while maintaining consistency across multiple pages. This required organizing reusable components, updating navigation across the site, and ensuring every new section matched the overall design language.
